# Phasix

A 2D top-down monster-tamer RPG built in Unity (Latest LTS, 2D URP). Players capture, raise, and
evolve **Phasix** — creatures that crystallize emotional states and coping mechanisms — through a
Digimon-style branching evolution web, in a world of Hubs and Realms that mirrors lived human
experience.

**Status:** active pre-alpha / early development. Core systems (creature data, bond system,
personality, companion following, wild encounter scaffolding) are in place; combat, evolution
execution, and world content are still being built out.
